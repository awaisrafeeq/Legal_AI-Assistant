Root Causes

🧬 Root Causes — Deep Dive
6 fundamental problems jo tera RAG break kar rahe hain
Top-K Hard Limit — 🔴 Critical
Tera system sirf top 5 ya top 10 chunks return karta hai. Agar kisi person ki 20 declarations hain aur wo scattered hain index mein, to sirf 5 aa rahi hain. Baaqi 15 miss ho jaati hain.
Fix: top_k=50 karo + metadata filter lagao person name par
Chunking Breaks Entity Context — 🔴 Critical
1000-token chunks mein ek declaration ka naam sirf pehle chunk mein hoga. Baaki chunks mein 'he/she/il/elle' pronouns honge. Vector search un chunks ko miss kar deta hai kyunki name nahi hai.
Fix: Parent-Child chunking + entity header har chunk mein add karo
No Metadata Filtering — 🔴 Critical
Abhi tera hybrid search pure index mein jaata hai bina kisi person/doc-type filter ke. Sirf vector similarity se top results aate hain. 170GB data mein relevant chunks dab jaate hain.
Fix: Classification complete hone ke baad persons[] field par OData filter lagao
Vector Search Miss on Names — 🟡 High
text-embedding-ada-002 proper nouns (person names) ko well represent nahi karta. 'Jean Dupont ki declaration' aur 'declaration by Jean Dupont' ke embeddings similar nahi hote legal French mein.
Fix: BM25 keyword weight badhao names ke liye + query rewriting mein name explicitly add karo
Cross-Encoder Kills Recall — 🟡 High
Cross-encoder reranking ke baad sirf top 5 results jaate hain GPT ko. Lekin recall phase mein already bahut kum documents aa rahe hain. Reranker precision deta hai lekin recall nahi badhaata.
Fix: Pehle recall fix karo (top_k=50, filters), phir reranker ko 50→10 karo
No Entity Extraction in Query — 🟠 Medium
Query "is bandy ki sari declaration chahiye" se person name extract nahi ho raha. System ko pata nahi kaunsa banda hai. Sirf semantic search pe depend hai jo names ke liye weak hai.
Fix: NER (Named Entity Recognition) query pe lagao ya GPT se entity extract karwao

Reranking

⚡ Reranking Strategy Fix
Cross-encoder ko sahi jagah use karo — recall ke baad, pehle nahi
⚠️ Critical Misunderstanding
Tera cross-encoder abhi already-limited results ko rerank kar raha hai.
Agar pehle hi sirf 5 results hain, cross-encoder kuch bhi fix nahi kar sakta.
Reranker ek precision tool hai, recall tool nahi.

Prompt Fix

📝 Prompt Engineering Fix
System prompt jo completeness enforce kare + perfect citations de
🔢 Count Enforce — GPT ko batao kitne docs mile, wo sab cite kare
📄 Structured Citations — File name, type, date, download link — formatted table
⚠️ Incompleteness Flag — Agar results lagein incomplete, explicitly warn karo
🌐 Language Aware — Urdu/English query → same language jawab, French legal terms rakhein
